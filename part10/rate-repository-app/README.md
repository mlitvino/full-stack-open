# Rate Repository App

## About

A React Native (Expo) mobile app for browsing and reviewing GitHub repositories, built for Part 10 of Full Stack Open. Repositories can be sorted, filtered by keyword and paginated; signed-in users can create reviews, view their own reviews and delete them. Data comes from the `rate-repository-api` GraphQL server via Apollo Client.

## Running it with Expo Go

Install [Expo Go](https://expo.dev/go) on your phone.
